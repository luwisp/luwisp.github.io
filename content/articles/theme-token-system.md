# 用主题 Token 管理配色

主题文件放在 `themes` 目录，每个文件只描述名字、类型、色板和 CSS 变量。展示端不关心主题来自哪里，只把 token 写入 `documentElement`。

## Token 的优势

同一个布局可以切换不同色彩系统，因为组件不直接依赖具体颜色。

如果把主题看成向量，可以粗略表示为：

$$
T = (bg, surface, text, muted, accent)
$$

切换主题就是把 $T_a$ 替换成 $T_b$，而组件结构保持不变。

## 明暗主题

- 亮色主题用于白天和高环境光。
- 暗色主题用于夜间和低环境光。
- 用户选择会保存在浏览器本地。

## 后续管理

管理端只要生成新的主题 JSON 并更新 `themes/index.json`，展示端就能自动加载。
