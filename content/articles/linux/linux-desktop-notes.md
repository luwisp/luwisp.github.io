桌面环境配置往往散落在设置面板、脚本和记忆里。把它写成文章，可以把审美选择和操作步骤留在同一个地方。

## 记录什么

- 主题和壁纸来源。
- 快捷键和窗口规则。
- 脚本、插件、启动项。
- 为什么最后选择这一套配置。

## 可复现比截图更重要

截图只能保存结果，文字和代码能保存过程。

```bash
kpackagetool6 --type Plasma/Wallpaper --upgrade ./wallpaper
```

## 和博客风格的关系

这也是博客采用桌面风格的原因：它不只是展示文章，也是在展示一种长期使用的个人环境。
